# Beer Lens Skill

Beer Lens 把现场酒单转换为可解释的精酿购买建议：先核对酒款和报价，再按预算、风格、ABV、IBU 与口味约束筛选，最后展示实际杯价、容量、单位价和备选差价。

## 适用问题

- “预算 70 元，不太苦，选哪杯？”
- “第 2 款怎么样？”
- “这两杯按单位价哪个更合适？”
- “这瓶是什么酒？评分对应的是不是同一款？”

它不负责交易支付，也不会把公共评分当成个人喜好或市场最低价。最终用户不需要登录 Untappd；公共评分查询只是可选证据，来源不可用时仍可依据菜单事实回答。

## 安装

把整个 `beer-lens` 目录复制到支持 `SKILL.md` 的 Agent Skills 目录。目录结构必须保留：

```text
beer-lens/
  SKILL.md
  scripts/decide-menu.mjs
  examples/menu.json
```

脚本要求 Node.js 20 或更高版本，不需要安装额外依赖：

```bash
node scripts/decide-menu.mjs --input examples/menu.json
```

也可以从标准输入传入 JSON：

```bash
node scripts/decide-menu.mjs < menu.json
```

## 输入与输出

输入为结构化菜单：货币、当前约束和多个报价。完整字段示例见 [`examples/menu.json`](examples/menu.json)。宿主可以从中文或英文文本、菜单照片或酒标照片提取这些字段。

输出 JSON 包含：

- `recommendations`：确认符合硬约束的 0—3 个选择；
- `excluded`：被预算、ABV、IBU、风格或未知字段阻止的报价；
- `comparison`：首选与备选的总价差、可比时的单位价差；
- `warnings`：币种、数据缺失与证据边界。

## 决策规则

- 数值预算、ABV、IBU 与排除风格是硬约束，未知值不算通过。
- 明确说“按单位价”才按每 100ml 排序；总价超预算时，单位价再低也不能成为首选。
- “性价比”采用口味、证据、价格的分项理由，不使用评分除价格的万能分数。
- IBU 只是苦度线索，不保证实际感知；缺少 IBU 时只能谨慎参考风格。
- 评分必须匹配到同一酒款和酒厂；酒厂均分、近似名称或广告语不能冒充单款评分。

## 隐私与限制

- 默认不保存或上传图片、位置、购买记录和口味反馈。
- 当前 helper 默认把同一次输入中的价格视作同一币种；币种未知时仅做菜单内部的数值比较并给出警告。
- 不同包装、堂饮与外带、套餐和跨门店报价需要额外规格信息，不能直接比较。
- 识图质量取决于宿主提供的视觉能力；脚本只负责确定性约束和价量计算。
