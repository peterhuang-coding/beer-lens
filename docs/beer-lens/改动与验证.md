# 改动与验证

本次提交将飞书试用接入、对话规则修复、图片评测材料与回复设计一起收录。代码实现、离线验证、真实模型验证和设计提案分别记录，不把素材准备或设计样例当作产品验收通过。

## 代码改动

| 改动 | 行为 | 主要位置 |
|---|---|---|
| 飞书长连接试用 | 官方SDK接收私聊，支持可选用户白名单；与HTTP入口共用消息处理器 | scripts/feishu-bot.ts、lib/feishu/trial.ts、lib/feishu/handler.ts |
| 聊天队列和重置 | 同聊天串行，跨聊天互不等待；重置当前对话及短期菜单，长期偏好保留 | lib/feishu/queue.ts、lib/beer-agent/memory/short-term.ts |
| 回复错误识别 | 检查飞书业务返回码，不把HTTP成功等同于消息发送成功；错误日志不回显提供方响应 | lib/feishu/client.ts |
| 预算与容量更新 | 新值替换同维度旧值，保留其他条件；价格、容量、ABV、IBU不混用；支持“改为473ml” | lib/beer-agent/recommendation/constraints.ts |
| 路由与实体提取 | 数值条件更新承接当前菜单，普通请求不直接变成酒名 | lib/beer-agent/intent-registry.ts、lib/harness/router-rules.ts、lib/beer-agent/recommendation/menu-input.ts |
| 否定编号 | “不要第7号和第18号”排除对应菜单编号；解析与最终推荐使用一致的否定判定 | lib/beer-agent/recommendation/menu-input.ts、lib/beer-agent/recommendation/purchase.ts |
| 缺失字段提示 | 无候选满足容量等要求时明确提示，不默认放行未知容量 | lib/beer-agent/recommendation/decision.ts |

## 图片统计与来源

累计69个图片文件＝63张来源图＋6张衍生图，不等于69款酒。来源图中存在同款的照片/海报、相近包装系列；按family_id分组，后续数据分割需防止同族泄漏。新增真实现场菜单照片为0。

第二批：京A16张、Toppling Goliath 5张、Side Project 10张、Other Half 2张。图中品牌不能代替具体酒款身份；无酒精、历史奖项和版本细字单独检查。MBCB仅确认北京活动和对应年份海报，逐厂名单尚未核实，不能把这些酒厂自动认定为本届参展方。

原图版权归各自权利人；来源公开可访问不等于开放许可。文件保存用于可追溯评测，清单逐项保留官方页面和图片直链，不包含登录资料、个人数据库或运行时凭据。
